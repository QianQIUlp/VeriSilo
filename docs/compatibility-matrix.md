# Compatibility matrix

| Target                                                | Status                                                       | Notes                                                                                                                                                                                                  |
| ----------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Windows 10 x64                                        | planned validation target                                    | Desktop installer and browser discovery require Windows end-to-end verification.                                                                                                                       |
| Windows 11 x64                                        | planned validation target                                    | Desktop installer and browser discovery require Windows end-to-end verification.                                                                                                                       |
| Chrome Stable                                         | supported target                                             | Uses Chromium command-line profile isolation and Manifest V3 companion APIs.                                                                                                                           |
| Edge Stable                                           | supported target                                             | Uses the same MV3 source with its own Store ID and Native Messaging registration.                                                                                                                      |
| Labs: new classic Dedicated Worker                    | implemented best-effort experiment                           | Default off and current-site opt-in; covers only new same-origin/blob classic Workers plus a same-origin iframe self-test. User-triggered injection order is unproven, so it never reports `verified`. |
| Labs: Cookie virtualization / Set-Cookie interception | unsupported in stock MV3                                     | Cards are unselectable; page-visible Cookie canary observation is read-only. Use an independent desktop `user-data-dir` or a stronger engine/environment layer.                                        |
| Fixed HTTP/SOCKS5 proxy                               | implemented, needs Windows E2E                               | Optional credentials use a loopback relay; SOCKS5 auth is checked before launch, HTTP auth by real request.                                                                                            |
| External Mihomo/Clash API                             | implemented adapter                                          | User-run core only; loopback Controller, stable selector/node binding, no bundled GPL binary.                                                                                                          |
| Camoufox managed engine                               | standalone Linux prototype accepted on branch                | v3 Identity Artifact and Host evidence exist on `codex/camoufox-m0-m2-minimal` / Draft PR #10, not on `main`; native Windows M2-W and desktop integration remain blocked.                              |
| Controlled Chromium                                   | deferred; conditional reevaluation only                      | It is not a parallel current track. Reopen only for a documented Chromium compatibility, TLS/QUIC, extension-ecosystem, or Camoufox maintenance requirement.                                           |
| WSL Chromium                                          | V0.8 controller implemented; Windows E2E blocked             | Fixed guest-agent lifecycle and self-hosted SOCKS5H exit/proxy-DNS evidence exist. Guest OS resolver stays unavailable; no TUN/OS-wide enforcement claim.                                              |
| Windows Sandbox                                       | V0.8 host lifecycle implemented; guest evidence unavailable  | Default-deny descriptor plus exact tracked-process start/health/log/stop/destroy. No reliable guest return channel, required proxy, DNS, or browser-ready claim.                                       |
| Hyper-V                                               | V0.8 control plane implemented; external image/agent blocked | Exact VM/image receipt and lifecycle controls exist. A lawful pinned VHDX with reviewed guest agent plus real signed Windows acceptance is still required for guest/browser/network evidence.          |
| Self-hosted remote agent                              | V0.9 scheduled option                                        | User-owned node first; no default VeriSilo public cloud or implicit data upload.                                                                                                                       |
| macOS/Linux                                           | not yet supported                                            | Deferred until Windows release behavior and installer safety are validated.                                                                                                                            |
| Multiple concurrent Silos                             | not yet supported                                            | Intentionally blocked by the runtime manager in V0.1.                                                                                                                                                  |
