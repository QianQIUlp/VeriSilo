# Non-goals

- No automatic installation of a Chrome or Edge store extension into a newly created browser profile.
- No import, export, cloning, or restoration of browser cookies or default-profile state by the desktop core.
- No browser-policy installation for consumer users.
- No cloud sync, telemetry, advertising, or project-operated IP-echo endpoint.
- No random-per-call fingerprint spoofing or "undetectable" marketing.
