# Non-goals

Updated 2026-11-10 by the [commercial direction decision](product-direction-decision-2026-11.md). That decision removed two earlier non-goals: cookie import and export into a Silo is now in scope (roadmap P3.7), and optional end-to-end encrypted sync is in scope (roadmap Phase 6).

- No reading, importing, cloning or modifying of the user's default Chrome, Edge or Firefox profile on VeriSilo's own initiative. Cookie and Silo imports happen only from files the user chooses.
- No automatic installation of a store extension into a newly created stock browser profile. Per-Silo extension management in VeriSilo-built engines is planned (P5.7).
- No browser-policy installation on consumer machines.
- No default telemetry, no advertising, and no project-operated IP-echo endpoint.
- No sync or hosted service that can read customer data. Sync, when added, is end-to-end encrypted.
- No per-launch or per-call fingerprint randomization by default.
- No "undetectable" marketing and no promise to bypass anti-fraud systems.
- No CAPTCHA solving, no synthetic human-like input meant to defeat bot detection, no payment or identity-verification fraud tooling, and no automated mass account registration.
- No VeriSilo-operated proxy marketplace and no "IP purity" scores.
- No mobile device emulation or cloud phones.
